Este proyecto consiste en la recreación tridimensional, interactiva y fotorrealista de un escenario deportivo de **Básquetbol** en tiempo real. Desarrollado en **C++** utilizando **OpenGL moderno (versión 3.3+)**.

---

### Requisitos Previos y Dependencias
Para poder clonar, compilar y ejecutar correctamente este escenario 3D, es necesario contar con las siguientes herramientas y bibliotecas de desarrollo instaladas en el sistema:

* **Git:** Para control de versiones y clonación del repositorio.
* **Compilador C++:** Compatible con el estándar C++17 o superior (GCC, Clang o Visual Studio MSVC).
* **OpenGL:** Versión 3.3 o superior soportada por la tarjeta gráfica.
* **GLEW (OpenGL Extension Wrangler Library):** Para la gestión de extensiones de OpenGL.
* **GLFW3:** Para la creación de ventanas, contextos y control de eventos de entrada (teclado y mouse).
* **GLM (OpenGL Mathematics):** Biblioteca de matemáticas orientada a gráficos 3D (vectores y matrices).
* **Assimp (Open Asset Import Library):** Para la importación y carga de modelos 3D en formatos como `.obj`, `.fbx` y `.gltf`.
* **stb_image.h:** Utilidad ligera de carga de texturas (incluida en las cabeceras del proyecto).
